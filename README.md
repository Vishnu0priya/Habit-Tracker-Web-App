# Habit-Tracker-Web-App
A simple and interactive Habit Tracker built using HTML, CSS, and JavaScript that helps users track daily and weekly habits, maintain streaks, and visualize progress — all stored locally in the browser.
🚀 Features

Add daily or weekly habits with custom targets

Mark and unmark habit completion by date

View streaks, 30-day progress, and overall statistics

Interactive progress visualization using Chart.js

Edit or delete habits anytime

Export and import habit data as JSON

Fully responsive UI

No backend required — uses localStorage
🛠️ Technologies Used

HTML5 – Structure

CSS3 – Styling & responsive design

JavaScript (ES6) – Logic & DOM manipulation

Chart.js – Data visualization

Browser localStorage – Data persistence
📊 Data Storage

All habit data is stored locally in the browser using localStorage

Data persists even after page refresh

Users can export data as a JSON file for backup
🔄 Import & Export

Export: Download all habit data as habits.json

Import: Upload a previously exported JSON file to restore data
